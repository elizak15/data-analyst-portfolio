Hi! This repository is my data analyst portfolio.

All projects here are personal **pet projects created for learning purposes**. They use practice datasets, so the figures do not describe real companies.

Each project follows the full analytics cycle: data cleaning and preparation, calculation of business metrics, analysis, dashboards, and clear recommendations for the business.
